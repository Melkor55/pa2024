- Disclaimer: I am using the 3.12.8 version of python(from https://www.python.org/downloads/windows/)

- Before running the file, the main dependencies have to be installed

pip install mpi4py
pip install Cython

- Then, we need a working MPI implementation like MPICH or Open MPI(Only linux). For Windows there is MS-MPI(Microsoft MPI) that can be downloaded from https://www.microsoft.com/en-us/download/details.aspx?id=105289
- Now everything should be setup and ready to run...

- To run this file use:

mpiexec -n $NUMBER_OF_PROCESSES python $PATH_TO_FILE

-------------------------------------------
The python file contains the 3 required functions followed by the test cases for each of them.
- My_MPI_Broadcast
Broadcasts a value from the root process to all other processes using a binary tree communication pattern. 
Each process sends the data to its designated partner determined by a mask, ensuring efficient propagation.

- My_MPI_Reduce
Performs a reduction operation (e.g., sum) across all processes, combining data element-wise from all ranks and storing the final result in the root process. 
It uses a tree-based communication approach, where ranks exchange and merge data progressively.

- My_MPI_Barrier
Implements a synchronization point for all processes. 
Each process communicates with its designated partner in a binary tree pattern, ensuring no process proceeds until all have reached the barrier.
